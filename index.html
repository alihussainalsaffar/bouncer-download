BOUNCER

Install Bouncer

Flutter project by Ali Alsaffar

Android

Download the game and install it on your phone. Tilt the phone to move the tile.

Download for Android (44 MB)
  1. Open the downloaded file.
  2. If asked, allow installing from this source.
  3. Tap Install, then Open.

iPhone

iPhone apps can't be installed from a web page, so this opens the same game in Safari. The browser may not pass the tilt to the game, so you can also drag the tile with your finger. On a computer, use the arrow keys.

Open Bouncer in the browser
  1. Tap Share in Safari.
  2. Tap Add to Home Screen to keep it as an icon.
Source code is in the private Gitea repo aalsaffar/bouncer.
